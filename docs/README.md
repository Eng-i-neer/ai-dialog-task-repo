## 文件详细说明

### `代码文档管理总控.md` — 代码文档管理系统
- **作用**：@ 引用时自动扫描项目中所有代码文件，发现未记录的新文件并更新对应目录的 README.md
- **核心功能**：扫描 → 对比 → 分析 → 更新 README → 汇报

### `自动执行规则.md` — 自动执行规则（项目内备份）
- **作用**：存放三条自动执行规则的内容，作为项目内的参考副本
- **规则内容**：命令行错误防范/记录、对话记录自动追加、代码文档自动更新

### `实现方案.md` — 减肥日志系统实现方案
- **作用**：完整的系统实现方案文档，指导整个项目的开发
- **核心内容**：需求分析、技术栈选型、UI 设计风格、6 张数据库表结构详细设计、API 路由规划、AI 智能分析系统设计、前端页面规划、性能策略、5 阶段实施步骤
