### Step 2：创建 `backend/init_db.py` — 建表脚本

- **目标**：执行 6 张表的 CREATE TABLE 和索引创建
- **要点**：

  - `user_settings`：id(CHECK=1), target_weight, height_cm, gender, birth_date, activity_level, ai_api_key, ai_api_url, ai_model, vision_api_key, vision_api_url, vision_model, created_at, updated_at
  - 所有索引按方案创建
  - `user_settings` 插入默认行 `INSERT OR IGNORE`
  - 提供 `__main__` 入口，运行后打印"✅ 数据库初始化完成"
- **验证**：运行 `python backend/init_db.py`，数据库文件创建成功，表结构正确

### Step 4：创建 `backend/routes/weight.py` — 体重 CRUD API

- **目标**：实现体重记录的完整 CRUD
- **参考**：加油站系统 `routes/expenses.py` 的代码风格（Blueprint + get_db + dict_row/dict_rows）
- **路由**：
  - `POST /api/weight` — 新增（自动填充 recorded_at 和 date）
  - `GET /api/weight?date=YYYY-MM-DD` — 查某天所有记录
  - `GET /api/weight/<id>` — 查单条
  - `PUT /api/weight/<id>` — 修改
  - `DELETE /api/weight/<id>` — 删除
- **内部逻辑**：
  - POST 时自动生成 `recorded_at`（当前时间 ISO 格式）和 `date`（从 recorded_at 截取）
  - POST/PUT/DELETE 成功后触发 `_update_daily_summary(conn, date)` 私有函数更新 daily_summary（自愈机制）
- **`_update_daily_summary(conn, date)`**：
  - 从 `weight_records` 查当天所有记录
  - 计算 morning_weight（time_of_day='morning' 的第一条）、lowest、highest、avg、count
  - 从 `meal_records` 查当天 SUM(calories) + SUM(ai_calorie_estimate)
  - 从 `exercise_records` 查当天 SUM(calories_burned)
  - 计算 weight_change（今天 morning_weight - 昨天 morning_weight）
  - UPSERT 到 daily_summary
- **要点**：在 `app.py` 中注册此蓝图
- **验证**：curl/浏览器测试 POST 和 GET

### Step 5：创建 `backend/routes/settings.py` — 用户设置 API

- **目标**：实现设置的 GET/PUT
- **路由**：
  - `GET /api/settings` — 获取设置（单行表，直接返回第一行）
  - `PUT /api/settings` — 更新设置（只更新传入的字段）
- **要点**：
  - GET 时如果没有记录，返回默认值结构
  - PUT 用动态 SQL 构建更新语句，只更新请求中包含的字段
  - 在 `app.py` 中注册此蓝图
- **验证**：curl 测试 GET 和 PUT
