## 快速开始

本项目刚刚初始化，尚无业务代码。以下是文档管理系统的使用方式：

### ⭐ 自动执行（推荐 — 零操作）

AI 在每次对话中自动执行三条规则：

| 行为 | 触发时机 | 效果 |
|------|----------|------|
| 🛡️ 错误防范 | 执行命令前 | 自动检查历史错误，主动避坑 |
| 📝 错误记录 | 命令出错后 | 自动记录到 `logs/命令行错误记录.md` |
| 📝 对话记录 | 完成重要任务后 | 自动追加到 `logs/对话记录.md` |
| 📋 文档更新 | 创建/修改文件后 | 自动更新对应 `README.md` |

### ⚡ 斜杠命令

| 命令 | 功能 |
|------|------|
| `/record` | 记录当前对话的重要内容 |
| `/errors` | 记录命令行错误 + 自查防范 |
| `/scan-docs` | 扫描新文件并更新 README |

### 📎 @ 引用

| 文档 | 功能 |
|------|------|
| `@[logs/对话记录.md]` | 追加重要对话内容 |
| `@[logs/命令行错误记录.md]` | 记录错误 + 自查防范 |
| `@[docs/代码文档管理总控.md]` | 扫描并更新 README |
