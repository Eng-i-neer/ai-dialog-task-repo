# 📂 logs/ — 运行日志与记录

> 本目录存放对话记录和错误日志，作为持续积累的知识库。

---

## 文件列表

| 文件 | 功能 | 说明 |
|------|------|------|
| `对话记录.md` | 对话记录 | @ 引用时自动追加重要对话内容 |
| `命令行错误记录.md` | 错误记录 | @ 引用时记录命令行错误并自查防范 |

---

## 文件详细说明

### `对话记录.md` — 对话记录系统
- **作用**：@ 引用时自动将当前对话的重要内容追加记录
- **记录内容**：关键决策、技术方案、架构设计、重要代码变更、Bug 修复、待办计划
- **格式**：按日期分组，每条记录含时间、类别、摘要、详情和相关文件

### `命令行错误记录.md` — 命令行错误避坑手册
- **作用**：双向机制 — 向后记录错误 + 向前主动避免重蹈覆辙
- **记录内容**：每条错误含错误命令、现象、根因分析、正确做法、教训
- **分类**：路径相关、Shell 语法、编码字符集、工具使用、依赖环境、其他
