### 修复云服务器数据库锁死和 UNIQUE 约束冲突
- **时间**：00:55
- **类别**：问题解决
- **摘要**：用户反馈手机和桌面端输入/删除数据时显示「网络连接失败」、页面卡顿无反应。通过 SSH 远程诊断发现双重数据库问题：SQLite database is locked + daily_summary 表 UNIQUE 约束冲突。修复后所有数据操作恢复正常。
- **详情**：
  - **症状**：GET 请求正常（页面能加载数据），但 POST/DELETE 请求返回 500 Internal Server Error
  - **根因1 — 数据库锁死**：多次部署时 `migrate_to_users.py` 反复备份 + WAL 日志未 checkpoint，产生 65+ 个备份文件，数据库被锁
  - **根因2 — UNIQUE 约束冲突**（核心）：`daily_summary` 表定义 `date TEXT NOT NULL UNIQUE`，添加多用户后同一天两个用户操作会触发 `UNIQUE constraint failed`
  - **修复1**：停服 → WAL checkpoint(TRUNCATE) → 清理备份至 3 个
  - **修复2**：重建 `daily_summary` 表，UNIQUE 约束改为 `UNIQUE(date, user_id)`
  - **修复3**：`db.py` 添加 `timeout=30` 防止并发锁超时
  - **修复4**：同步修改本地 `init_db.py` 中的表定义
  - **验证**：POST /api/exercise 和 POST /api/weight 均返回 201 成功，journalctl 零错误
- **相关文件**：`backend/init_db.py`、`backend/db.py`、服务器 `/opt/weight-tracker/backend/data/weight_tracker.db`
